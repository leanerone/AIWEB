# AI Hub 用户指南

> 面向公司内网同事的日常使用说明。

## 登录

- 打开平台后**自动尝试 Windows 域登录**：在公司域内电脑上、从本机启动后端时自动登录，无需输密码
- 自动登录不可用时（跨机器访问等）：输入用户名密码登录。初始内置账号见 README
- 右上角头像菜单可**退出登录**

## 首页（Bento 动态）

- **统计卡**：Skills / 小工具 / 插件 / 笔记数量，点击直达对应列表
- **最新动态**：AI 内容、资源、笔记、资讯混排，可按类型筛选，点击卡片跳转（AI 内容卡点击弹窗看全文）
- **AI 助手卡**：进入对话；「生成今日 AI 简报」一键抓取订阅资讯让 AI 写简报
- **贡献者榜**：资源×2 + 笔记/内容卡×1 的活跃度 Top 8

## 资源库

### 上传资源
1. 点「上传资源」，选择类型：**Skill**（SKILL.md 技能包）/ **小工具** / **插件**
2. 填名称 → 可点「AI 简介」让 AI 生成一句话简介
3. 可选：上传附件（SKILL.md / zip / 脚本，≤20MB，禁止 exe/msi 等可执行格式）
   - 上传 `.md` 或含 `SKILL.md` 的 zip 会**自动提取** name / description / tags 填表
4. 可选：填外链（Git 仓库 / 在线文档）

### 浏览与查找
- 顶部类型 Tab + 关键字搜索（含正文全文）+ 排序（最新/点赞/下载/浏览）
- 点卡片上的 `#标签` 快速按标签筛选；「我的点赞」只看收藏
- 点赞 ❤ / 下载附件 / 分享（复制内网链接发给同事）
- 详情页**讨论区**：留言提问、分享使用心得（可删自己的评论）
- 有权限的人（作者/管理员）可**编辑**、**删除**

## 笔记

- Markdown 编辑（工具栏支持粗体/斜体/代码/标题/列表/链接）
- **置顶**常用笔记；标签分类；关键字搜索
- 笔记里粘贴 `notes://` 链接会自动出现**琥珀色快捷卡**，点「在 Notes 打开」唤起 Notes 客户端
- 每条笔记可导出为 `.md` 文件（含 frontmatter）
- **Notes 链接库**：集中保存解析过的 Notes 链接，支持单条粘贴解析、批量导入（每行一条）、搜索

## AI 助手（悬浮窗）

AI 助手常驻右下角悬浮球，**任何页面点击即可唤起**，不再需要单独页面：

- **问答**：流式输出，可随时停止；回复可复制 / 重新生成 / ✦沉淀为首页内容卡
- **能干活**：助手可以直接帮你**搜平台资源、读笔记、查资讯**，也能**写笔记、收藏资源、生成简报、发布内容卡**
  - 写操作默认先弹**确认卡**征求你的同意；在「个人 AI 设置」开启「自动执行」后才会直接做
  - 需要决策时会弹**提问卡**（一次只问一个问题），点选项或输入回答即可继续
- **页面上下文**：自动带上你当前所在的页面（如在资源详情页问"这个怎么用"，助手知道是哪个资源），点上下文 chip 可关闭
- **历史会话**：面板左上「历史会话」图标，可切换 / 重命名 / 删除
- **建议卡**：悬浮球带红点提醒——今日简报就绪、24h 新资讯等，点开面板即可看到；只建议、不自动执行

### 个人 AI 设置

- 「设置 → 个人 AI 设置」（默认折叠）：填**你自己的** API Key（加密存储，仅本人可见）
- 不填则回落管理员配置的全局 Key；两者都可用时**你的 Key 优先**
- 点「测试连接」验证当前生效配置

## RSS 资讯

- 「设置 → AI 资讯订阅」添加 RSS 源（内置示例：Hacker News AI）
- 「全部刷新」手动抓取；后端**每小时自动刷新**一次
- 每条资讯可：打开原文 / 存为笔记 / ✦ AI 生成知识卡（进首页动态）
- 源出错时显示 ⚠ 错误信息

## 设置

| 区域 | 说明 |
|---|---|
| 个人 AI 设置 | 每人自己的 Key / Base / 模型 / 人设（加密存储，默认折叠） |
| AI 资讯订阅 | 订阅源管理 + 最新资讯列表 |
| 成员管理（仅管理员） | 创建成员账号、设置角色；下载数据备份（SQLite） |

> 管理员注意：全局兜底 Key 请配置在 `backend/.env`（`AI_API_KEY`），此界面不再保存全局键。

## 全局能力

- `Ctrl/⌘ + J`：唤起 / 收起 AI 助手悬浮窗
- `Ctrl/⌘ + K`：全局搜索页面 / 资源 / 笔记 / Notes 链接；无结果时直接「问 AI 助手」
- 顶栏铃铛：今日新增动态数
- 深色模式：顶栏月亮/太阳切换，自动记忆
- 右下角回到顶部按钮（悬浮球上方）

## 资源版本历史

- 资源每次**更新前自动快照**旧版本；资源详情页（仅创建者/管理员可见）可查看历史版本列表
- 「回滚」一键恢复到任意历史版本；回滚前当前内容也会被快照，可再滚回来

## 常见问题

**Q：notes:// 链接点了没反应？**
本机需安装 HCL Notes 客户端且协议关联正常。可用平台里的 `fix-notes-protocol` 工具修复。

**Q：AI 报"未配置"？**
到「设置 → 个人 AI 设置」填你自己的 API Key；内网私有化部署也可由管理员在 `backend/.env` 配全局兜底键。

**Q：忘记密码？**
管理员在「设置 → 成员管理」重新创建账号，或改 `backend/.env` 的 `DEFAULT_USER_PASSWORD` 后重启（会重置未改过密码的账号）。
